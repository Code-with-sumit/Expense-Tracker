# Expense Tracker

A simple Expense Tracker application built using Python. This project helps users record and manage their daily expenses.

## Features

- Add new expenses
- View all expenses
- Store expense data in JSON format
- Export expenses to CSV
- Track spending records easily

## Technologies Used

- Python
- JSON
- CSV

## How to Run

1. Clone the repository
2. Open the project folder
3. Run the following command:

```bash
python ExpenseTracker.py
```

## Files

- ExpenseTracker.py - Main application
- expenses.json - Stores expense data
